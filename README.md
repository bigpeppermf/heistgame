## The game

**git money** is a two-player coding game with a board-game chase. One player is the cop, the other is the robber. Solve challenges in Python or JavaScript, earn movement, and use gadgets to mess with your rival.

Each round follows the same loop:

1. Read the challenge and write your solution against the clock.
2. Get scored on passing tests and code style.
3. Use gadgets to gain an edge or sabotage your opponent.
4. Move along the board based on your results.

The cop wins by catching the robber. The robber wins by reaching the escape space or staying ahead through three rounds.

## The stack

- **Frontend:** Next.js, React, TypeScript, and Tailwind CSS.
- **Code editor:** Monaco, with Python and JavaScript support.
- **Backend:** Node.js, Express, and Socket.IO for live matches.
- **Scoring:** Test-based correctness and Gemini code style reviews.
- **Shared logic:** TypeScript types, challenges, and game balance.
