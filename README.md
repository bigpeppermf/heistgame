## Inspiration
The process of learning about data structures and algorithms can be daunting for most people, with having to watch boring tutorials or do tedious practice problems. Git Money gives people a fun way practice these DSA problems in a fun and competitive boardgame style way.

## What it does
Git money is a heist themed game where two players compete in coding challenges to progress on a board game. One player starts as the cops and the other player starts as the heist team. The cops have to catch up to the heist team before they are able to escape.
## How we built it
- **Frontend:** Next.js , React , and Tailwind CSS 
- **Code editor:** Monaco, supporting Python and JavaScript challenges.
- **Backend:** Node.js and Express, with Socket.IO for real-time multiplayer.
- **AI code quality:** Google Gemini for code-style reviews
## Challenges we ran into
The main challenge encountered was definitely the whole back-end. Getting real time multiplayer to work took lots of troubleshooting, and stacking it on top of browser based code execution was a new experience. We also had to tinker with the style of the front-end a good bit before finding something we were happy with.

## Accomplishments that we're proud of
- Making a cool game that we enjoy playing
- Making our first real time multiplayer game
- Learning all about how websites like Geoguessr, Leetcode and other browser games actually work behind the scenes.
